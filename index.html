Windows Core

Ajustes fundamentales para reducir la latencia del sistema operativo.

⚠️ Desactivar Core Isolation (Importante)

La "Integridad de Memoria" virtualiza procesos y roba hasta un 15% de FPS.
Instrucciones: Copia el comando, abre CMD como Administrador, pega y dale Enter. Reinicia.
bcdedit /set hypervisorlaunchtype off

⚡ Plan de Energía Ultimate

Instrucciones: Copia el comando, pégalo en CMD (Admin) y luego ve a "Opciones de Energía" para seleccionarlo.
powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61

🎮 Modo de Juego

Pulsa tecla Windows > Escribe "Modo de juego" > ACTIVAR. Esto prioriza el juego sobre Windows Update.

Almacenamiento y Servicios

💾 Force TRIM (SSD Rápido)

Fuerza a Windows a limpiar bloques de memoria borrados al instante.
Instrucciones: Ejecutar en CMD como Administrador.
fsutil behavior set disabledeletenotify 0

🛑 Matar SysMain (Superfetch)

SysMain precarga apps que no usas en la RAM.
Instrucciones: CMD (Admin).
sc stop "SysMain" & sc config "SysMain" start= disabled

🕵️ Matar Telemetría

Desactiva el envío de datos a Microsoft.
sc stop "DiagTrack" & sc config "DiagTrack" start= disabled

🚫 Desactivar Indexing (Búsqueda)

Paso a Paso: 1. Abre "Este Equipo".
2. Click derecho en tu Disco Local (C:) > Propiedades.
3. Abajo del todo, DESMARCA "Permitir que los archivos... tengan contenido indizado".
4. Aplicar a todo (ignorar errores).

Red Avanzada (TCP/IP)

🌐 Algoritmo CTCP (Menor Ping)

Cambia el protocolo de congestión antiguo por uno moderno (Compound TCP).
Instrucciones: CMD (Admin).
netsh int tcp set global congestionprovider=ctcp

🧹 Flush DNS

Limpia caché corrupta de internet y resetea sockets.
ipconfig /flushdns && ipconfig /renew && netsh winsock reset

⚡ Tarjeta de Red

Admin. Dispositivos > Red > Avanzado:
1. Flow Control: Disabled
2. Interrupt Moderation: Disabled
3. Power Saving: OFF

Latencia de Entrada (Input Lag)

⏱️ Desactivar HPET (High Precision Event Timer)

HPET es un temporizador viejo que causa stuttering.
Instrucciones: 1. Click derecho en Inicio > Administrador de Dispositivos.
2. Despliega "Dispositivos del Sistema".
3. Busca "Temporizador de eventos de alta precisión".
4. Click derecho > Deshabilitar.

⌨️ Mouse & Teclado Buffer (Registro)

Aumenta la cola de datos para no perder clicks bajo carga pesada.
Instrucciones: Copia, guarda en un archivo de texto como fix.reg y ejecútalo.
Windows Registry Editor Version 5.00 [HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\mouclass\Parameters] "MouseDataQueueSize"=dword:0000012c [HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\kbdclass\Parameters] "KeyboardDataQueueSize"=dword:0000012c
